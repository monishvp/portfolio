# Monish P — Developer Portfolio 🚀

A modern, responsive, and performant personal developer portfolio built with **React**, **TypeScript**, **Tailwind CSS**, and **Vite**, featuring smooth scroll animations powered by **Framer Motion**.

🌐 **Live Demo:** [https://monishvp.github.io/portfolio/](https://monishvp.github.io/portfolio/)

---

## 🌟 Features

- 🌑 **Modern Dark UI:** Sleek cyberpunk-inspired dark theme with electric cyan (`#00d4ff`) and deep violet (`#7c3aed`) gradient accents.
- ✨ **Interactive Animations:** Smooth entrance and scroll-reveal transitions using Framer Motion.
- 📱 **Mobile-First & Responsive:** Fully optimized layout across mobile, tablet, and desktop screens with an interactive mobile drawer navigation.
- ⚡ **Lightning Fast:** Bundled with Vite for instant Hot Module Replacement (HMR) and ultra-fast production builds.
- 🛡️ **Type-Safe:** Built with TypeScript with strict typing across components and data schemas.
- 🎨 **Utility-First Styling:** Clean styling using modern Tailwind CSS v4.

## 🚀 Getting Started

### Prerequisites

Ensure you have the following installed on your machine:
- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- [Yarn](https://yarnpkg.com/) (`npm install -g yarn`)

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/monishvp/portfolio.git
   cd portfolio
   ```

2. **Install dependencies:**
   ```bash
   yarn install
   ```

3. **Start the local development server:**
   ```bash
   yarn dev
   ```
   Open [http://localhost:5173/portfolio/](http://localhost:5173/portfolio/) in your browser.

---

## 🏗️ Available Scripts

- `yarn dev` — Runs the development server with live reload.
- `yarn build` — Runs TypeScript type-checking (`tsc -b`) and bundles production assets.
- `yarn preview` — Previews the production build locally.
- `yarn deploy` — Builds the app and publishes the `/dist` directory to the `gh-pages` branch.
